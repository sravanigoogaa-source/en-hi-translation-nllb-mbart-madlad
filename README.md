# en-hi-translation-nllb-mbart-madlad
Fine-tuned and benchmarked NLLB-200, mBART-50, and MADLAD-400 for English–Hindi neural machine translation using the IIT Bombay parallel corpus. Compared translation quality across architectures via BLEU (sacrebleu) scores with Hugging Face Transformers, exploring how different multilingual NMT designs generalize on the same fine-tuning data.
